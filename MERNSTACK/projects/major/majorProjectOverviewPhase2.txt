:::::::::::::::::::::::::::::::::::::::: Major Project Phase 2 Part D - Authentication and Authorization ::::::::::::::::::::::::::::::::::::::::
Concepts:-------------------------------------------------------------------------------------
Authentication:
    It is the process of verify who is the someone.

Authorization:
    It is the process of verifying what accesses someone has.

Storing Password:
    We never store password as it is form.
    We store password in hashed form.
    Hashing functions are used convert password into hashed form.

Hashing:
    It has fixed length for every input.
    Every different input there is different output but same length.
    Slight change in input will result into large chnage in output.

Salting:
    It is technique to generate hashed form  of the password by adding salt [string of 32 or more character] to it before actually storing  it into database.

Passport:
    Passport is authentication middleware for Node.js.
    Extremely flexible and modular.
    A comprehensive set of strategies support authentication using a username and password, Facebook, Twitter, and more.

    a. passport: Passport is Express-compatible authentication middleware for Node.js.
    Syntax: npm i passport

    b. passport-locals - Passport strategy for authenticating with a username and password.
    Syntax: npm i passport-local

    c. passport-local-mongoose: Passport-Local Mongoose is a Mongoose plugin that simplifies building username and password login with Passport.
    Syntax: npm i passport-local-mongoose
