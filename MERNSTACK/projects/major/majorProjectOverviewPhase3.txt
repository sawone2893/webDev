4. Image upload and save in local:
    a. We need to make form capable of sending files.
        i. We need to maniplulate the add new listing form [new.ejs].We need to set enctype ="multipart/form-data" for form.
          <form action="/listings" method="post" novalidate class="needs-validation" enctype="multipart/form-data">
        ii. We need to change type attribute value to file for input element [new.ejs].
          <div class="mb-3">
            <label for="image" class="form-label">Upload Listing Image</label>
            <input type="file" name="listing[image]" class="form-control" />
          </div>
        iii. Multer- Multer is a node.js middleware for handling multipart/form-data, which is primarily used for uploading files.
             Multer will not process any form which is not multipart (multipart/form-data)
             * We need to install multer library to achieve this.
                npm i multer
             * Now add below line of code to access upload file.
                const multer  = require('multer');
                const upload = multer({ dest: 'uploads/' });
             * Pass the middleware: upload.single(listing[image]') in your post route.
             * Access file attributes using below code
                req.file
5. Image upload and save in Cloud:
    a. We will use 3rd party service:Cloudinary.
    b. Create your account on Cloudinary Platform [https://cloudinary.com/users/register_free] using your GitHub account.
    c. We will stores our credentials inside .env file.
    d. To access .env file data we need to install dotenv library
        [Dotenv is a zero-dependency module that loads environment variables from a .env file into process.env.]
        npm i dotenv
        require('dotenv').config()
        console.log(process.env)
    e. Create a .env file and store CLOUD_NAME,CLOUD_API_KEY and CLOUD_API_SECRET in it.
    f. Add below code inside the app.js file at the very top for access .env file data.
      if(process.env.NODE_ENV!="production"){
        require('dotenv').config();
      }
    g. We need to install below libraries to store files in Cloudinary Platform.
        i. cloudinary - The Cloudinary Node SDK allows you to quickly and easily integrate your application with Cloudinary.
                        Effortlessly optimize, transform, upload and manage your cloud's assets.
                        npm i cloudinary

        ii. multer-storage-cloudinary - A multer storage engine for Cloudinary.
                                        npm i multer-storage-cloudinary
    h. Now ,create a cloudConfig.js file where we will setup configuration to connect with Cloudinary Platform.
    i.Then, use cloudConfig  in add new listing [routes/listing.js] request for upload images to Cloudinary Platform.
        const multer = require("multer");
        const {storage} = require("../cloudConfig");
        const upload = multer({ storage });
