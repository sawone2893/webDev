React:
=====
    i. It is javascript library for creating UI.
    ii. React apps are made out of components.A component is a piece of the UI (user interface) that has its own logic and appearance. 
    iii. A component can be as small as a button, or as large as an entire page.
    iv. React components are JavaScript functions that return markup.
    
JSX:
====
 Javascript Extension Syntax
 It alllows us to write HTML inside javascript.
 Internal Conversion: JSX===>Babel===>JS

2. Creating our own component and Rendering a component:
    Syntax:component creation
        function NameOFtheComponent(){
            return (
                <h1>Hello World</h1>
            );
        }
    Syntax:rendering component
        <ComponentName></ComponentName>
                    or
        <ComponentName/>
    
    Example:
    function Title(){
        return (
            <h1>Hello World</h1>
        );
    }
       <Title> </Title> 
            or
       <Title/>       
3. Writing markup in JSX:
    a. Return a  single root element.
    b. Close all the tags.
    c. camelCase most of the things.

    Example:

    function Description(){
        return (
        <p className="desc">I am description</p>
        );
    }
4. React Fragment:These let you group a list of children without adding extra node to the DOM.
    <></> These are call react Fragment

    Example:
        function Title(){
        return (
            <>
            <h1>Hello World</h1>
            <h3>Hello World</h3>
            </>
        );
    }

6. Importing and exporting component:

    a. A file can only have one default export, but it can have numerous named exports!
    b. Use default exports if the file exports only one component
    c. Use named exports if it exports multiple components and values.

        --------------------------------------------------------------------------------------------
        | Syntax	    Export statement	                    Import statement
        | Default	    export default function Button() {}	     import Button from './Button.js';
        | Named	        export function Button() {}	            import { Button } from './Button.js';
        --------------------------------------------------------------------------------------------
